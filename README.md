This project was developed as part of NTI MEAN Stack Training, focusing on applying JavaScript fundamentals,
DOM manipulation, and data validation by building a complete student management system from scratch.
 # Features :
 - Add a new student with full details
 - Update student information easily
 - Delete a specific student
 - Delete all students at once
 - Confirmation message before deleting any student or all students
 - Search for a student by name
  If the student is not found, the system displays "Unavailable"
- Automatically calculate the total grade
- Determine student status (Pass / Fail) based on total grade
- Validate grades input:
  -Only positive values are allowed
  -Grades must be within a specific valid range
- Save all student data using Local Storage
# Technologies Used :
- HTML
- CSS
- JavaScript
- Local Storage
# How It Works :
- The user adds a student with all required details
- Student data is saved automatically in Local Storage
- Users can:
    -Update any student record
    -Delete a specific student or all students
- A confirmation message appears before any delete action
- Users can search for students by name:
    -If no matching student is found, "Unavailable" is displayed
- The system calculates the total grade for each student
- Based on the total grade, the system determines whether the student is:
 -Pass
 -Fail
- Grade inputs are validated to ensure correctness
- All data persists after refreshing the page
